# 06 · 自研表单控件与 UI 优化

> 日期：2026-11-25
> 范围：全部表单控件、租约备注、运营台状态信息、表单可访问性
> 约束：不引入 UI 组件库；不改变路由、API、请求/响应结构；保持亮暗双主题

## 1. 目标

本次做两件事：

1. **表单控件全部项目化**：下拉框、日期选择、数字输入、搜索框、文本框、富文本框、按钮、分页器都不再直接使用浏览器原生外观，而是使用项目自己的 Tailwind 组件。
2. **按 impeccable 的 Operate 模式做 UI 优化**：运营台首先追求可扫描、可预期、可键盘操作；品牌感放在控件细节、状态信息和数据呈现里，而不是装饰性特效。

本次使用已安装的 impeccable skill 的 Operate 模式。`context` 检查显示项目暂无 `PRODUCT.md` / `DESIGN.md`；因为这是既有代码的局部 UI 修复，按 skill 规则继续，不阻塞，并建议后续运行 `/impeccable init` 补充产品上下文。完成后运行 `impeccable detect --json frontend/src`，结果 0 findings。

## 2. UI 审计发现

| 问题 | 影响 | 处理 |
|---|---|---|
| 原生 `<select>` 与项目边框、圆角、主题不一致 | 切换暗色主题时控件像“浏览器默认控件” | 新增自研 `Select`，选项列表使用 portal + 键盘导航 |
| 原生日期/数字输入依赖浏览器 UI | 日期不可快速切换月份，数字无步进器和单位 | 新增 `DatePicker`、`NumberInput` |
| 长列表下拉被 Modal 的 `overflow` 裁剪 | 车型、车辆、门店等长选项选择困难 | Popover 使用 `createPortal` + 视口定位，自动向上/向下展开 |
| 原生搜索框无清空按钮、尺寸不统一 | 筛选区密度不一致 | `SearchInput` 增加 `sm/md/lg`、清空、快捷键、自动聚焦 |
| Field 的 label 与自研控件缺少关联 | 屏幕阅读器读不到字段名/当前值 | 新增 `FieldContext`，label、error、hint 自动关联到控件 |
| 错误状态只有一行红字 | 表单错误不够醒目，缺少 `role=alert` | 错误增加图标、`role="alert"`、`aria-invalid`、`aria-describedby` |
| 租约备注只能纯文本 | 交接说明无法加粗、列点 | `RichTextEditor` + 白名单清洗 + 详情渲染 |
| 桌面端服务状态不可见 | 运营台缺少“系统是否在线”的即时反馈 | Dashboard 增加运营状态条；侧边栏与登录页展示服务在线状态 |
| 按钮 loading 无 aria 状态 | 无障碍反馈不足 | `Button` 增加 `aria-busy` |

## 3. 自研控件清单

### 3.1 Select

文件：`frontend/src/components/ui/select.tsx`、`SelectPanel.tsx`、`select-helpers.ts`

- 触发器是项目按钮，支持 `sm/md` 两种高度。
- 选项通过 `<option>` 子元素传入，兼容原有页面写法；也支持没有 `value` 的颜色选项。
- 选项超过 8 个时自动显示搜索框，输入后列表过滤，搜索框不会因为结果变少而消失。
- 支持键盘：`ArrowUp/Down`、`Home/End`、`Enter`、`Escape`、`Space`；`Tab` 会关闭面板并进入下一个字段。
- 面板通过 portal 渲染到 `body`，在视口内自动选择向上或向下展开，滚动/缩放时重新定位。
- 空值选项作为占位文案显示（如“选择车型”“全部门店”），不会被误认为已选中；选中项显示对勾。
- 支持 `disabled`、`aria-label`、`aria-expanded`、`aria-controls`、`aria-describedby`。

### 3.2 DatePicker

文件：`frontend/src/components/ui/date-picker.tsx`

- 项目自己的日历面板，月份切换、星期标题、按周补齐的日期网格、今天、清除日期。
- 支持 `min`、`max`、`disabled`、`sm/md`。
- 键盘 `Escape` 关闭，`Tab` 关闭并进入下一个字段；选择后自动关闭并回焦触发器。
- 面板同样使用 portal，避免被筛选卡或 Modal 裁剪；移动端 304px 宽，不超出 390px 视口。

### 3.3 NumberInput

文件：`frontend/src/components/ui/number-input.tsx`

- 左右减/加按钮，支持 `step`、`precision`、`min`、`max`、`prefix`、`suffix`。
- 输入法 `inputMode="decimal"`；箭头键上下步进；失焦时格式化并在范围内收敛。
- 不再使用浏览器原生 spinner，视觉与 Select/Input 完全统一。

### 3.4 RichTextEditor / RichTextViewer

文件：`frontend/src/components/ui/rich-text.tsx`、`frontend/src/lib/sanitize.ts`

- contentEditable 富文本框，工具栏包含加粗、斜体、下划线、无序/有序列表、链接、清除格式、撤销。
- 工具栏按钮使用 `onMouseDown` 保留选区；选中文字后加粗可正确写入 `<b>`。
- 粘贴时只接收纯文本；保存与渲染前使用 `sanitizeHtml` 白名单清洗。
- 白名单标签：`b/strong/i/em/u/ul/ol/li/p/br/div/span/a`；`a` 只允许 `http/https/mailto`，并补 `rel="noreferrer noopener"`。
- `RichTextViewer` 用于租约详情备注；纯文本旧数据也能正常显示。
- 链接使用自研 `RichTextLinkPopover`，不再调用原生 `window.prompt`；支持 URL 校验、Esc/Enter/点击外部关闭，并保留编辑选区。

### 3.5 Input / Textarea / SearchInput

文件：`frontend/src/components/ui/input.tsx`、`form.tsx`

- 统一 44px 高度（筛选紧凑态 40px）、8px 圆角、边框、阴影、focus ring、disabled 状态；表面样式收敛到 `.field-control` / `.field-control-invalid`。
- `SearchInput` 支持尺寸、自动聚焦、清空、`onKeyDown` 和 250ms 防抖，用于全局搜索、筛选与下拉搜索；筛选页输入时只在本地草稿层更新，提交后才触发 URL 与请求。
- `Input` / `Textarea` 自动读取 `FieldContext` 的 `id`、错误和提示，并写入 `aria-invalid` / `aria-describedby`。
- `Input` / `Textarea` / `SearchInput` 均有 24px 圆形清空按钮；密码框不显示清空按钮，只保留显示/隐藏密码。

### 3.6 Field

- `Field` 现在渲染为 `div + label[for] + context`，不再用 label 包裹整个控件。
- 自动生成 `id`；label、错误、提示与控件关联。
- 必填星号、错误图标、错误 `role="alert"`。
- 覆盖 Select、DatePicker、NumberInput、Input、Textarea、SearchInput 和 RichTextEditor。

### 3.7 Button / ButtonLink

- 项目主/次/危险/幽灵变体，`sm/md/lg` 尺寸，loading 指示器。
- `buttonClassName` 提供共用样式；`ButtonLink` 用于导航场景，避免 `<Link><Button>` 的嵌套交互元素。
- 增加 `aria-busy`；保留键盘 focus ring。
- 图标按钮、日历天、Tab、分页等专业控件内部仍使用语义化按钮，但视觉由设计 token 控制。

## 4. 全量替换情况

以下原生控件已全部替换，`grep` 检查不再有业务页面直接使用：

- `<select>` / `<option>`：筛选、表单、分页每页条数。
- `<input type="date">`：车辆保险/年检、司机驾照、维保计划、调拨计划、收款日期、违章日期、报表区间、租约起租日。
- `<input type="number">`：里程、费用、押金、月租、评分、容量、罚款、扣分、收款金额、提醒天数。
- 业务页面中的原始 `<input>`：全局搜索对话框改为 `SearchInput`。
- 租约备注：`Textarea` 改为 `RichTextEditor`；租约详情使用 `RichTextViewer` 渲染。

## 5. UI 优化

### 5.1 Dashboard 运营状态条

在页面标题和主视觉之间增加一条真实数据状态条：

- 服务在线 / 服务异常（来自 `GET /api/health`）
- 车队规模
- 运营门店数
- 本月到期未收
- 数据更新时间

它在桌面端一行展示，在移动端自动换行；没有使用装饰性假数据。

### 5.2 全局服务状态

- 侧边栏底部显示“服务在线 / 服务异常”。
- 登录页品牌面板底部显示服务状态。
- 使用 `useHealth` 60 秒轮询；首次加载时不会误报离线。

### 5.3 视觉系统细节

- 控件高度：表单 44px、筛选 40px、按钮 40px；搜索 `sm` 40px、`md` 44px、`lg` 48px。
- Tabs 文案 14px；表格表头 12px、数据默认 14px、表格内次级说明 12px。
- 主内容滚动条品牌橙色；下拉与内部滚动条蓝色半透明。
- 紧凑搜索/下拉字号 14px；统计卡 hover 背景变化并过渡 200ms。
- 主内容滚动条宽 8px、不透明轨道；内部 thin 8px、透明轨道；全项目无上下箭头。
- 圆角：控件 8px，浮层 12px；与项目 Card 的 shape lock 一致。
- 浮层：`animate-fade-up` 180ms；已有 `prefers-reduced-motion` 降级。
- 错误：图标 + 文案 + `role=alert`；不再只有一行红字。
- 空值占位：Select 的空选项显示为 muted 文案，不再与已选值混淆。
- 暗色主题：所有新控件使用 `bg-card`、`border-line`、`text-ink`、`text-muted` 等语义 token。
- 信息小块收敛到 `.info-tile` / `.info-tile-compact`，避免同一层级出现 `/30`、`/40` 两套背景。

## 8. 边界与后续

- 富文本基于 contentEditable + `document.execCommand`，浏览器支持广但属于旧 API；如果后续要做协同编辑、图片粘贴或更复杂排版，建议迁移到 TipTap/Lexical。
- 当前富文本只用于租约备注；备注在数据库仍是字符串，API 结构未变。
- Popover 定位基于视口和触发器；如果未来出现多层嵌套滚动容器，可以引入 Floating UI 做更完整的 collision detection。
- 服务状态是前端健康检查，不代表所有业务接口都可用；后续可扩展为更细的依赖健康面板。
