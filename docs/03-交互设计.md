## 1. 设计读数

> Reading this as: 内容驱动的网约车租赁运营台，实拍车辆与 3D 车身作为视觉主角，运营数据以不同尺寸卡片、进度条和图表嵌入，整体保持统一的间距、圆角和字体层级。

**三档参数**

| 参数 | 值 | 说明 |
|---|---|---|
| DESIGN_VARIANCE | 6 | 后台可预测，但总览用 7/5、4/4/4、8/4 非对称网格 |
| MOTION_INTENSITY | 5 | 主题扩散、抽屉、状态反馈、图表入场 |
| VISUAL_DENSITY | 6 | 表格紧凑，但给摄影留呼吸 |

**taste-skill 边界**

taste-skill 明确不覆盖 dashboard 与数据表格。本项目只吸收其通用设计纪律：反模板、单一强调色、形状锁、字体纪律、真实三态、动效动机、WCAG AA、Pre-flight。运营表格按 B 端最佳实践执行。

### 2.2 字体

- 西文与数字：Geist Variable
- 等宽：Geist Mono Variable
- 中文回退：PingFang SC、Noto Sans SC、Microsoft YaHei
- 字号：12 / 13 / 14 / 16 / 22 / 28
- 金额、车牌、租约号、账单号、里程、百分比统一 `font-mono`

### 2.3 形状

| 元素 | 圆角 |
|---|---|
| 卡片、面板 | 12px (`rounded-xl`) |
| 按钮、输入、下拉 | 8px (`rounded-lg`) |
| 状态标签 | 全圆角 |
| 图片容器 | 12px |

### 2.4 间距与密度

- 8px 基线
- 页面水平内边距：16px (手机) / 24px (桌面)
- 内容最大宽度：1600px
- 表格行高：约 44px
- KPI 条用 1px 分隔，不做卡片堆叠

### 2.5 阴影

- 亮色：`0 1px 2px rgba(16,24,32,.04), 0 12px 32px rgba(16,24,32,.05)`
- 暗色：`0 1px 0 rgba(255,255,255,.03), 0 18px 48px rgba(0,0,0,.28)`
- 暗色以边框和层次为主，不依赖重阴影

## 6. 主题切换交互

### 6.1 触发

- 顶栏主题按钮
- 登录页右上角按钮
- 固定从页面左下角开始扩散

### 6.2 动画

```text
1. 固定圆心为页面左下角（0% / 100%）
2. 调用 document.startViewTransition
3. 在回调中写入 data-theme 和 localStorage
4. 新主题层从左下角圆形扩散，700ms
5. 旧主题层保持不动，新主题层覆盖
```

CSS：

```css
::view-transition-old(root) { animation: none; z-index: 1; }
::view-transition-new(root) {
  z-index: 2;
  animation: theme-reveal 700ms cubic-bezier(.16,1,.3,1);
}
@keyframes theme-reveal {
  from { clip-path: circle(0 at 0% 100%); }
  to { clip-path: circle(150vmax at 0% 100%); }
}
```

### 6.3 过渡

- 切换期间给 `html` 加 `theme-switching`
- 颜色、背景、边框 240ms 过渡
- 布局、尺寸、字体、间距不变
- 图片只做轻微亮度变化，不改变裁切
- 3D 容器背景与阴影随主题变化，不重新加载模型

### 6.4 降级

- 不支持 View Transitions：180ms 淡入
- `prefers-reduced-motion`：立即切换
- 首屏内联脚本读取 localStorage，避免闪烁

## 7. 状态设计

| 状态 | 表现 |
|---|---|
| Loading | 骨架屏匹配最终布局，不用圆形 spinner 作为主加载 |
| Empty | 图标 + 标题 + 说明 + 可选操作 |
| Error | 错误图标 + 说明 + 重试 |
| Success | Toast，4.2 秒自动消失 |
| Disabled | 降低透明度，保留原因说明 |
| Conflict | 表单内错误或 Toast，明确“车辆已锁定/司机有租约” |
